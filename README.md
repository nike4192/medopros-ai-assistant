# Medopros MVP

Медицинский ассистент для автоматизации опроса пациентов.

## Функционал

- Запись аудиосообщений пациентов.
- Автоматическая транскрибация (ASR): GigaAM-v3 (Сбер) локально через
  [`onnx-asr`](https://github.com/istupakov/onnx-asr); Whisper через OpenRouter —
  запасной движок (`ASR_ENGINE=openrouter` включает его как основной).
- Анализ текста с помощью LLM для извлечения жалоб и симптомов.
- Интеграция с Telegram для уведомлений о новых заявках.
- Админ-панель для просмотра истории записей.

## Установка и запуск

### Локально

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Настройте переменные окружения:
   Скопируйте `.env.example` в `.env` и заполните необходимые ключи:
   ```bash
   cp .env.example .env
   ```

3. Запустите сервер:
   ```bash
   python backend.py
   ```
   Приложение будет доступно по адресу `http://localhost:8001`.

### Docker

Запуск через Docker Compose:
```bash
docker-compose up -d --build
```

## Структура проекта

- `backend.py` - Основной API сервер (FastAPI).
- `index.html` - Лендинг.
- `app/` - Фронтенд приложения ассистента.
- `assets/` - Статические файлы (картинки, стили).
- `recordings/` - Директория для хранения аудиозаписей и JSON данных (игнорируется в Git).

## ASR

По умолчанию распознавание идёт локально моделью **GigaAM-v3** (`gigaam-v3-e2e-rnnt`,
ONNX int8, CPU). Модель (~230 МБ) скачивается с Hugging Face при первом старте в
`~/.cache/huggingface`; в docker-compose этот каталог смонтирован с хоста, так что
повторные запуски модель не качают.

Настройки (`server/config.py`, переменные окружения):

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `ASR_ENGINE` | `gigaam` | `gigaam` или `openrouter` (прежний Whisper) |
| `GIGAAM_MODEL` | `gigaam-v3-e2e-rnnt` | имя модели в каталоге `onnx-asr` |
| `GIGAAM_QUANTIZATION` | `int8` | `int8`, `fp16` или пусто (fp32) |
| `GIGAAM_MAX_SPEECH_S` | `25` | окно VAD-нарезки, с |
| `GIGAAM_WARMUP` | `1` | греть модель в фоне при старте |
| `ASR_FALLBACK_OPENROUTER` | `1` | откат на Whisper, если GigaAM упала |

## Безопасность

Все секретные ключи должны храниться в файле `.env`. Никогда не пушьте `.env` в репозиторий! Для этого уже настроен `.gitignore`.
